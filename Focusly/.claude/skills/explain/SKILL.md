# Объяснение

Тема: $ARGUMENTS

1. Найди, где тема встречается в `docs/macos-swiftui-guide.md` (урок, врезка «Паттерн»), и опирайся на неё, а не противоречь ей.
2. Структура ответа:
   - **Суть** в 2–3 предложениях: какую проблему решает.
   - **Без него** — короткий пример, где проблема видна (код ≤ 15 строк).
   - **С ним** — тот же пример, исправленный (код ≤ 25 строк).
   - **Когда не нужен** — честно: где это оверинжиниринг.
   - **Альтернативы** — таблица, если есть с чем сравнить (enum vs протокол, класс vs структура, `@State` vs `@Bindable` и т. п.).
   - **В Focusly** — одной-двумя фразами: где это появится или уже есть (урок N), **без кода проекта**.
3. Примеры — из другой предметной области (кофейня, библиотека, плеер, склад), чтобы пользователь сам переносил идею на свой проект.
4. Если вопрос про API, которое могло измениться, сверься с документацией Apple, а не с памятью.
