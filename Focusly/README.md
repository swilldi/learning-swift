# Focusly — учебное macOS-приложение на SwiftUI

Курс-проект, чтобы вспомнить Swift + SwiftUI и прокачать ООП: за 14 уроков с нуля пишется
macOS-приложение для работы по технике помидора (задачи, таймер, статистика, строка меню),
а по дороге — MVVM, Repository, Strategy, State, Command, Decorator, Adapter и другие паттерны.

## С чего начать

1. Откройте методичку: [docs/macos-swiftui-guide.md](docs/macos-swiftui-guide.md) → **Урок 0**.
2. Откройте Claude Code в этой папке и напишите `/lesson`.

## Что где

| Путь | Что это |
|---|---|
| [docs/macos-swiftui-guide.md](docs/macos-swiftui-guide.md) | методичка: 14 уроков, практика, финальное задание, шпаргалка |
| [docs/PROGRESS.md](docs/PROGRESS.md) | чек-лист прогресса |
| `FocuslyCore/` | Swift-пакет ядра: логика и тесты — создаётся в Xcode в уроке 0 |
| `Focusly/` | Xcode-проект приложения — создаётся в уроке 0 |
| `scripts/check.sh` | стиль + сборка + тесты одной командой |
| `scripts/run.sh` | собрать и запустить приложение |
| [CLAUDE.md](CLAUDE.md) | правила для агента: он наставник, код пишете вы |
| `.claude/` | скиллы агента и хук, запрещающий ему писать `.swift`-файлы |

## Агент-наставник

| Команда | Что делает |
|---|---|
| `/lesson` | где я, что готово, что дальше; отмечает прогресс |
| `/check` | прогнать проверки и объяснить ошибки (без исправлений) |
| `/hint …` | подсказка по уровням: направление → инструмент → каркас |
| `/mentor-review` | ревью ваших изменений |
| `/explain …` | объяснить понятие или паттерн на стороннем примере |

Режим наставника выключается файлом-флагом: `touch .claude/mentor-off` (включить обратно — `rm .claude/mentor-off`).

## Проверка

```bash
./scripts/check.sh          # всё
./scripts/check.sh core     # только ядро
./scripts/check.sh test Foo # тесты по имени
./scripts/check.sh app      # только сборка приложения
```
