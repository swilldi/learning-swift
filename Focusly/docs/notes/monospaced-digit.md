# .monospacedDigit(): цифры одинаковой ширины

Разбирали 2026-11-05, урок 3: модификатор встретился в строке задачи (счётчик помидоров).

## Суть

В системном шрифте (SF Pro) цифры по умолчанию **пропорциональные**: `1` уже, чем `0` или `8`.
Пока текст статичен, это красиво. Но если число меняется на месте, вместе с ним меняется ширина
текста — и всё вокруг «дрожит»: соседние элементы сдвигаются, в таблице столбцы не выравниваются.

`.monospacedDigit()` переключает **только цифры** на табличные (все одинаковой ширины). Буквы,
знаки и эмодзи остаются как были, шрифт тот же.

## Пример: часы на табло вокзала

```swift
struct DepartureBoard: View {
    @State private var seconds = 0

    var body: some View {
        VStack {
            Text("Отправление через \(seconds) с")              // фраза «прыгает»
            Text("Отправление через \(seconds) с")
                .monospacedDigit()                             // стоит на месте
        }
        .task {
            while !Task.isCancelled {
                try? await Task.sleep(for: .seconds(1))
                seconds += 1
            }
        }
    }
}
```

На `11 → 12` или `19 → 20` верхняя строка заметно меняет ширину, нижняя — нет.

## Сравнение

| | Без модификатора | `.monospacedDigit()` | `.monospaced()` | `.font(.system(.body, design: .monospaced))` |
|---|---|---|---|---|
| Что моноширинное | ничего | только цифры | все символы | все символы |
| Шрифт | системный | тот же системный | моноширинный вариант (SF Mono) | SF Mono |
| Вид | обычный текст | обычный текст | «как в терминале» | «как в терминале» |
| Когда | статичный текст | таймеры, счётчики, цены, столбцы чисел | код, хэши, выравнивание всего текста | то же, но задаёт и размер |

## Подводные камни

- **Две версии модификатора.** У `Text` есть свой `.monospacedDigit()`, он возвращает `Text` (такие
  куски можно склеивать через `+`). У `View` — свой: он действует на шрифт всех текстов внутри,
  поэтому его можно повесить на `HStack` целиком. Он не заменяет шрифт, а меняет тот, что уже действует.
- **Выравнивание столбца ≠ одинаковая ширина чисел.** `7` и `12` всё равно разной длины по количеству
  цифр. Чтобы столбец выровнялся по правому краю, нужно ещё выравнивание контейнера
  (`.frame(alignment: .trailing)`, `Grid`).
- **Не у всех шрифтов есть табличные цифры.** У системных — есть; у произвольного кастомного шрифта
  модификатор может ничего не изменить.
- **Анимация цифр — отдельная вещь.** `.contentTransition(.numericText())` анимирует смену цифр,
  а `.monospacedDigit()` лишь фиксирует их ширину. Часто их ставят вместе.
